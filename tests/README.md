## 書き方の決まり

- 時間に関するテストは `now` を注入した偽の時計で行う。`sleep` で偶然に頼らない。
- GameCore のレースはスクリプト式エンジンで、キューへの投入順を直接決めて再現する。
- 子プロセスを使うテストは、終了後にプロセスが残っていないことまで確認する。
- ソークテストは乱数シードを局ごとに記録し、違反した局のイベントログを保存する。
